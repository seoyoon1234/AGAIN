# AGAIN prototype

Map-first mobile prototype for discovering Korean Hidden Frames, listening to short voice stories, and adding a viewpoint to an existing route.

## Run locally

```powershell
node build.mjs
npx serve dist
```

The prototype intentionally has no login. Saved scenes use browser-local state in the interactive demo. Replace the simulated voice progress with pre-generated ElevenLabs MP3 files before the hackathon presentation.
